# WebNika Studio

Multilingual React service website for offering custom web development to local businesses.

## Features
- English, Ukrainian and Polish translations
- Light and dark themes with saved preference
- Light, Basic and Pro service packages
- One-time, monthly and yearly maintenance plans
- Live portfolio previews and external project links
- Trust-focused developer introduction using CV information
- Testimonial carousel
- Functional plan ordering modal with pre-filled email request
- Responsive navigation and layouts

## FAQ and conversion additions

- Complete multilingual FAQ accordion
- Free-consultation callout before pricing
- Final FAQ contact callout
- Design-guidance and business-visibility positioning
- Customer-focused design and content proposal section
